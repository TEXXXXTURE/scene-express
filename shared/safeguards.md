# shared/safeguards.md — 通用保真护栏

> 全场景通用的底线，所有模块卡必须遵守。本文件只保"真"，不管风格；风格与场景限制全部在模块卡里。
> 校验时按打分循环执行（tools/checker.md），本护栏对应"保真维"扣分项。

---

## 1. 只改"怎么说"，不改"说什么"

- 可以调整结构、句长、语气、词汇，**不得改变原文的事实、观点、立场与结论**。
- 用户给的材料是"说什么"的唯一来源；任何增删必须以材料为依据。

## 2. 不编造

- **不编造事实、数字、来源、引用、立场**。
- 材料中没有的信息，不补；不确定的数字，标注"待核"或省略，不写近似值充数。
- 涉及外部引用（报告、数据、网址）时，只使用材料中真实存在的。

## 3. 不越界

- 不改动用户已给出的结论、数据口径与备注；个人判断必须与材料判断分开标注。
- 材料内存在分歧时，如实呈现分歧，不用"各说各有理"之类的模板话带过。

## 4. 不确定就说明

- 对材料的理解存在歧义且影响结论时，先问，不猜。
- 交付时说明依据：哪些来自材料、哪些是推断、哪些待核。

---

## 校验区（保真维扣分项）

| # | 扣分项 | 判定方式 |
|---|---|---|
| 1 | 编造事实 / 数字 / 来源 / 引用 | LLM 判定：逐项核对材料 |
| 2 | 改变材料结论或立场 | LLM 判定：与材料观点对比 |
| 3 | 把推断写成事实（未标注） | LLM 判定：检查表述确定性 |
| 4 | 关键歧义未确认即自作主张 | 流程检查：是否已先问 |

> 保真维是唯一允许"零容忍"的维度：编造来源/事实直接判不合格，不进入重试预算的"容忍区"。
