# shared/safeguards.md — 通用保真护栏

> 全场景通用的底线，所有模块卡必须遵守。本文件只保"真"，不管风格；风格与场景限制全部在模块卡里。
> 校验时按打分循环执行（tools/checker.md），本护栏对应"保真维"扣分项。

---

## 1. 只改"怎么说"，不改"说什么"

- 可以调整结构、句长、语气、词汇，**不得改变原文的事实、观点、立场与结论**。
- 用户给的材料是"说什么"的唯一来源；任何增删必须以材料为依据。

## 2. 不编造

- **不编造事实、数字、来源、引用、立场**。
- 材料中没有的信息，不补；不确定的数字，标注"待核"或省略，不写近似值充数。
- 涉及外部引用（报告、数据、网址）时，只使用材料中真实存在的。

## 3. 不越界

- 不改动用户已给出的结论、数据口径与备注；个人判断必须与材料判断分开标注。
- 材料内存在分歧时，如实呈现分歧，不用"各说各有理"之类的模板话带过。

## 4. 不确定就说明

- 对材料的理解存在歧义且影响结论时，先问，不猜。
- 交付时说明依据：哪些来自材料、哪些是推断、哪些待核。

---

## 校验区（保真维扣分项）

| # | 扣分项 | 判定方式 |
|---|---|---|
| 1 | 编造事实 / 数字 / 来源 / 引用 | 机器检查：数字一致性 + 引语（§2） |
| 2 | 改变材料结论或立场 | 机器检查：极性（§2） |
| 3 | 把推断写成事实（未标注） | 机器检查：因果 + 标注位扫描（§2） |
| 4 | 关键歧义未确认即自作主张 | 流程检查：是否已先问 |

> 保真维是唯一允许"零容忍"的维度：编造来源/事实直接判不合格，不进入重试预算的"容忍区"。

---

## 2. 保真维机器检查（P0-2 · 四项可执行检查）

> 目的：把保真判定从"LLM 自由判断"升级为**确定性可执行检查**——每项有明确输入、步骤与判定规则，可由脚本或 Agent 逐项执行，产出结构化报告。四项全过 = 保真维通过；任一不合格 = 保真维不合格（零容忍，直接重写）。

### 输入

- **M**：材料文本（用户给的原文，"说什么"的唯一来源）
- **O**：产出文本（待交付文本）
- 标注位：O 中的"待核 / 推断"标记（护栏 4 要求）

### 检查 1 · 数字一致性（number-check）

- **步骤**：从 M 抽取全部数字记号（含小数 / 百分号 / 年份 / 金额 / 单位），从 O 抽取全部数字记号；O 中每个数字逐一在 M 中查找（同值 + 同语境单位）。
- **判定**：O 中数字不在 M 且未标"待核" → 不合格；全部匹配或已标待核 → 通过。
- **输出**：未核实数字列表（含出处句）。

### 检查 2 · 极性（polarity-check）

- **步骤**：对 M 与 O 的关键断言 / 结论句做极性标注（正向 / 负向 / 中性）；同主体断言逐一对比方向；检查程度副词是否被放大（轻微→显著、小幅→大幅、增长→飙升）。
- **判定**：同主体断言方向反转 → 不合格；程度夸大 → 扣分（每处 1 分）。
- **输出**：反转断言清单、夸大清单。

### 检查 3 · 因果（causality-check）

- **步骤**：抽取 M 的因果结构（因为 / 所以 / 导致 / 由于 / 归因于 / 由此）；对照 O 中对应事件关系，核对：①方向是否颠倒（A→B 写成 B→A）；②是否新增材料没有的因果；③是否把并列 / 时序写成因果。
- **判定**：因果颠倒 / 新增因果 → 不合格；并列写成因果等弱化 / 强化 → 扣分。
- **输出**：因果问题清单。

### 检查 4 · 引语（quote-check）

- **步骤**：抽取 O 中引号内容与"据来源 / 报告 / 网址 / 学者称"表述；逐字比对 M 原文；来源名称、网址必须存在于 M。
- **判定**：引语与原文不符 / 来源或网址不在 M → 不合格。
- **输出**：引语不符清单、来源缺失清单。

### 报告格式（保真检查输出）

```
保真检查：
- 数字一致性 ✓/✗（未核实：…）
- 极性 ✓/✗（反转：…；夸大：…）
- 因果 ✓/✗（问题：…）
- 引语 ✓/✗（不符：…；来源缺失：…）
结论：合格 / 不合格 → 重写原因
```

### 说明

- 四项检查是**先决步骤**，在 LLM 判定之前执行；LLM 判定仅用于无法穷举的语境判断（如情绪、隐含立场），不再承担数字 / 引语 / 极性 / 因果的核对。
- 检查所需的 M 必须是用户提供的原始材料；材料缺失时，先要材料再写作，不空跑检查。
