# shared/metrics.md — 表述指标词典

> 本文件是整个 Skill 的**脊柱**：指标提取器（tools/extractor.md）按它从样例中提取指标，模块卡按它定义参数档位，交付校验（tools/checker.md）按它打分。
> **一套指标，双向复用**：提取时用来"量"样例，校验时用来"量"产出。

---

## 0. 使用方式

- **提取方向**（样例 → 模块卡）：对每篇样例逐项测量 → 跨篇取共性 → 数值翻译成行为描述 → 写入模块卡。
- **校验方向**（模块卡 → 产出）：把模块卡里的档位当作目标值，对最终文本逐项测量 → 偏离即扣分。
- 指标共 **13 项**，分 6 个维度：信息、句法、词汇、语气、结构、修辞。

---

## 1. 档位通用定义

以下档位在 13 项指标中反复出现，先定义，避免每项重复。

### 句长档
| 档位 | 平均句长（字） | 一句话说明 |
|---|---|---|
| 短 | ≤ 20 | 短句为主，信息点碎而密 |
| 中 | 20–35 | 长短夹杂，自然阅读节奏 |
| 长 | ≥ 35 | 长句为主，书面与铺陈感强 |

### 情绪档
| 档位 | 情绪词密度 | 一句话说明 |
|---|---|---|
| 零 | 几乎不出现 | 只陈述事实与判断，不带感情色彩 |
| 克制 | 少量 | 允许轻态度词，不渲染 |
| 放开 | 明显 | 允许情感渲染、修辞与感染力 |

### 词汇档
| 档位 | 常用词占比 | 一句话说明 |
|---|---|---|
| 低难 | 高频词为主 | 口语化、人人可懂 |
| 中难 | 混合 | 书面但不过度术语 |
| 高难 | 术语/书面词明显 | 面向专业读者 |

### 解释腔开关
| 档位 | 含义 |
|---|---|
| 关 | 禁止"本质上/换句话说/也就是说"类句式 |
| 开 | 允许对概念做展开解释 |

### 结论位置档
| 档位 | 含义 |
|---|---|
| 先结论 | 首段即给核心结论，后补细节 |
| 先铺垫 | 先给背景/过程，结论在后 |
| 混合 | 视内容弹性安排 |

## 2. 指标词典（13 项）

### 维度 A · 信息

#### 1. 结论位置
- **定义**：核心结论出现在全文的位置。
- **提取方法**：读首段（前 15% 篇幅），判断是否包含全文核心结论；再看结论是否被推迟到末段。
- **档位**：先结论 / 先铺垫 / 混合。
- **落到模块卡**：表达倾向 → 信息组织（先结论后细节 / 先铺垫后揭示）。

#### 2. 信息密度
- **定义**：有效信息句占全部句子的比例。有效信息句 = 承载事实、数据、判断、动作的句子；客套、铺垫、重复、水词句不算。
- **提取方法**：逐句判定有效/无效，计算有效占比。
- **档位**：高（≥70%）/ 中（50–70%）/ 低（<50%）。
- **落到模块卡**：表达倾向 → 取舍标准（删什么、留什么）。

### 维度 B · 句法

#### 3. 平均句长
- **定义**：按句号、问号、感叹号分句后，每句平均字数。
- **提取方法**：总字数 ÷ 句数。
- **档位**：短 / 中 / 长（见 1.1）。
- **落到模块卡**：参数档位 → 句长档。

#### 4. 句长方差
- **定义**：句子长度的离散程度，衡量节奏是否机械。
- **提取方法**：计算各句字数的标准差；方差过大 = 节奏混乱，过小 = 节奏机械（每句一样长）。
- **档位**：自然（长短交替有呼吸感）/ 机械（接近等长）。
- **落到模块卡**：表达倾向 → 节奏倾向。

### 维度 C · 词汇

#### 5. 常用词占比
- **定义**：常用高频词（口语/基础词汇表）占全文词数的比例。
- **提取方法**：用高频词表对全文切词命中统计。
- **档位**：低难 / 中难 / 高难（见 1.3）。
- **落到模块卡**：参数档位 → 词汇档。

#### 6. AI 词命中
- **定义**：shared/lexicon.md 词表中的 AI 高频词、模板连接词在全文出现的次数。
- **提取方法**：按 lexicon 词表逐词扫描计数。
- **档位**：命中数（绝对次数），0 次为优。
- **落到模块卡**：校验区 → 扣分项（命中即扣分，累计超阈值触发重写）。

### 维度 D · 语气

#### 7. 情绪词密度
- **定义**：情绪/态度词（如"非常、极其、令人、遗憾、惊喜"）占全文比例。
- **提取方法**：情绪词表命中 ÷ 总词数。
- **档位**：零 / 克制 / 放开（见 1.2）。
- **落到模块卡**：参数档位 → 情绪档。

#### 8. 人称频率
- **定义**："我 / 我们 / 你 / 你们"等代词的分布，衡量说话人与读者的距离。
- **提取方法**：按人称代词统计（我系 / 你系 / 无主语）。
- **档位**：无我无你（客观）/ 我系（亲历者视角）/ 你系（对话读者）。
- **落到模块卡**：表达倾向 → 读者距离。

### 维度 E · 结构

#### 9. 段落方差
- **定义**：段落字数的分布形态，衡量结构节奏。
- **提取方法**：统计各段字数，看分布是否均匀。
- **档位**：均匀（分段整齐）/ 弹性（长短段交错）。
- **落到模块卡**：表达倾向 → 结构倾向。

#### 10. 小标题密度
- **定义**：每千字的小标题/分节数量。
- **提取方法**：标题计数 ÷ 千字。
- **档位**：无（段落承接）/ 稀疏（≥1 个/千字）/ 密集（≥3 个/千字）。
- **落到模块卡**：表达倾向 → 组织方式。

### 维度 F · 修辞

#### 11. 解释腔频率
- **定义**："本质上 / 换句话说 / 也就是说 / 这意味着 / 其实"等解释性引导词的频率。
- **提取方法**：解释腔句式表命中计数。
- **档位**：开关见 1.4；开启时还需标注"适度"。
- **落到模块卡**：参数档位 → 解释腔开关；校验区扣分项（关闭场景）。

#### 12. 升华 / 金句频率
- **定义**：结尾拔高、金句、排比升华的出现频率。
- **提取方法**：检测末段是否有"总而言之 / 让我们 / 这不仅是……更是…… / 未来已来"类模式。
- **档位**：无（直收）/ 有（升华结尾）。
- **落到模块卡**：校验区 → 扣分项（多数工作场景禁升华）。

#### 13. 残留检测
- **定义**：客套话、免责声明、模板开场白等"无效残留"的出现次数。
- **提取方法**：检测"仅供参考 / 如有不妥 / 希望对您有帮助 / 欢迎交流指正 / 在当今……时代 / 随着……的发展"等模式。
- **档位**：0 次为优。
- **落到模块卡**：校验区 → 扣分项（多数场景禁残留）。

## 3. 提取时的三条纪律

1. **跨篇浓缩**：3-5 篇样例中，只有"多数样例共有"的特征才是稳定指标；单篇出现的是噪音，剔除。
2. **数值翻译**：测出的数值必须翻译成行为描述再进模块卡（"平均句长 12 字" → "短句为主"），不写原始数值。
3. **证据链**：每个写入模块卡的指标结论，必须能指回至少一处样例原文出处（tools/extractor.md 有格式要求）。
