# 模块：公众号 / 公开文章（03-public-article）— 半成品模板

> ⚠️ 本卡是**半成品**：框架已写好，**具体人设需要用户填写**。账号定位不同（行业号 / 个人号 / 品牌号），人设差异很大，无法内置一个通吃的答案。
> 使用前请补全下方【人设】段；未补全时先按 00-default 执行并提示用户补全。

## 触发
公众号 / 公开文章 / 科普 / 读者向内容。载体：文章；对象：公众读者、目标读者群；目的：表达观点、建立认同、让读者读完并记住。

## 人设（待用户填写——请用户回答三个问题后填入）
1. **这个账号是谁在说话？**（行业专家 / 亲历者 / 品牌官号 / 陪聊型朋友 …）
2. **和读者的关系是什么？**（老师教学生 / 朋友聊天 / 专家给建议 / 品牌对用户 …）
3. **为什么读者要信这段话？**（有从业经历 / 有数据 / 有独家信息 / 纯粹表达 …）

> 填法示例："一个在行业里做了 8 年的人，用大白话把行业里的门道讲给想入行的年轻人听。读者信我，因为我踩过的坑都写出来了。"

## 表达倾向（引导，框架）
1. **信息组织**：有观点、有节奏。开头抓住读者（悬念 / 反常识 / 具体场景），中段展开论证，结尾收束（可升华，但必须落在具体处，不喊口号）。
2. **取舍标准**：留"读者想知道"的内容，删"我想说但读者无感"的内容；一段只推进一个点。
3. **语气基调**：按人设定（平视 / 亲切 / 犀利），但始终像"人"在说话——有主语、有停顿、有具体例子。
4. **词汇句式**：长短句交错；允许口语与情绪（这是少数允许放开情绪的场景）；禁模板连接词与 AI 腔。

## 参数档位（待用户确认后填）
- 句长档：中（建议）
- 情绪档：克制到放开之间（视人设）
- 词汇档：中难（视读者群）
- 解释腔开关：开（允许对概念展开解释）
- 结论位置：混合
- 人称：你系（对话读者，建议）

## 示例锚点（待用户提供该账号代表作后替换）
> 无代表作时用占位说明：请用户提供 1–2 篇该账号"写得对"的文章，用 tools/extractor.md 提取指标替换本段。示例锚点必须来自真实风格，不凭空造。

## 兜底限制
1. 不编造事实 / 数据 / 案例 / 引用（保真护栏全量生效；观点可以有倾向，事实不能错）。
2. 禁模板连接词与 AI 高频词（启用 lexicon 组一、组二）。
3. 禁"我"系流水账式自嗨——情绪与观点服务于读者，不服务于作者。
4. 标题与实际内容一致，不标题党到误导。

## 校验区（扣分项）
| # | 扣分项 | 判定方式 |
|---|---|---|
| 1 | 编造事实 / 数据 / 案例 / 引用 | 保真维，零容忍 |
| 2 | 出现 lexicon 组一/组二词（≥3 处） | 词表扫描 |
| 3 | 开头无抓手（平淡开场、客套开场） | LLM 判定 |
| 4 | 段落无推进（一段车轱辘话反复说一个点） | LLM 判定 |
| 5 | 升华落空（结尾喊口号但无具体所指） | LLM 判定 |

阈值：扣分 > 3 触发重写，预算 2 次。

## 自检
交付前确认：人设已填（未填则先提示）、开头有抓手、段落有推进、事实无编造、结尾有实处。
